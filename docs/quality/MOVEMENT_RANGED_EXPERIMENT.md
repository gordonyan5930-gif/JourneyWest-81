# Quality B v0.4 · 移动 / 破空击实验

授权依据：用户反馈6544590655、独立审查5723433382及本轮明确任务。保留地图/悟空与原件，不进入完整Quality C或Boss/81关。支持弓箭手与唐僧仅为本技能威胁试验，不算完整队伍角色生产。

## 移动

smoothMovement.ts：八向A*用1/√2距离代价，对角必须两个相邻正交格均可通行；supercover DDA在同时过格角时检查两侧。sampleGeometryClear补充真实多边形6px脚底扫掠净距，避免只看格心穿过细角。string-pull只连接可视安全线段；24px以内角点圆弧离散为8段，每段复验，否则保留原角点。不是无约束Bezier穿障碍。

加速620、减速820世界像素/秒²，最大210，转向速率7弧度/秒，1/120秒子步。接近终点/急角提前制动，遇碰撞减速回退；不允许碰撞失败后硬改位置。树林×0.8、浅滩×0.65，跑步帧仍按实际累计距离推进。当前只有左右镜像与轻微转身倾斜，不冒充完整方向动画。

默认平滑八向；UI“旧四向对照”保留v0.3寻路/恒速，仅用于相同起终点比较，也有运动安全停止。新旧路线叠加可见。单元连续10次全图往返（20段）；Canvas浏览器另有20次真实短途点击。比较录屏相同输入(240,720)→(600,550)，旧/新顺序和耗时记录JSON；不是通过改地图减少折线。

## 如意金箍·破空击

在“弓箭手威胁实验”点悟空→技能→点弓箭手；Esc取消。射程外/遮挡/冷却/能量不足拒绝，不自动追击，不无代价全图秒杀。蓄势时停步转向，0.3秒后发出独立飞行棍影，飞行沿线重新检查地形与目标位置，命中才结算HP/打断/击退；点击不直接扣血或删怪。已射出的箭不会因射手死亡而消失，仍可能伤害唐僧。只有唐僧死亡判失败，无完整关卡奖励。

所有初始值在rangedCombat.ts RANGED/ARCHER/THREAT，运动值在MOVE；导航遮挡通过Navigation接口可替换。本实验保守地把不可通行地形均当LOS遮挡，尚未区分可飞越沟壑/矮栏的高度层。

| 参数 | 初值 |
|---|---:|
| 技能射程 | 420世界像素 |
| 伤害 / 射手HP | 55 / 100（需2次命中） |
| 冷却 / 能量消耗 | 3.5秒 / 25 |
| 能量上限 / 每秒回复 | 100 / 3 |
| 蓄势 / 棍影速度 | 0.3秒 / 850像素每秒 |
| 命中半径 / 打断时长 / 击退 | 20像素 / 1.5秒 / 10像素 |
| 射手前摇 / 间隔 / 伤害 / 箭速 | 1.6秒 / 1.1秒 / 20 / 420 |

这是可调试初值，不是已批准平衡。未来可比较延长射程但提高耗能、强化打断但减少伤害等独立升级方案；本轮不制作升级系统，也不替代筋斗云/毫毛/天兵技能。

## 证据与边界

新浏览器测试真实点地面/按钮/敌人；验证两次命中/能耗/冷却/打断/击杀/唐僧存活，并用同一场景不反击，让正常弓AI/飞行箭矢导致唐僧死亡。没有测试接口直接扣血。单测还覆盖穿角、20段全图安全轨迹、急角不环绕、减速、LOS/能量/射程、发射后遮挡变化。

演示录屏约50秒，报告用ffprobe核对实际WebM30—60秒，缺文件或时长不符不能标技术通过。新旧截图和JSON包含同起终点。CI无录像WebGL/Canvas均跑相同实验；耗时含比较/战斗/截图，不直接与v0.3旧流程FPS作收益百分比比较。保留旧25怪5秒控制及原护卫/死亡/复活回归。真实Mac/Safari/120秒和人工手感仍未通过。

辅助弓箭手/Tang图集为一次原创生成的关键姿势试制，非母版裁片，非完整角色/生产动画。棍影使用运行FX素材的一段杆身，不是概念板。箭矢为小型程序纹理用于实际飞行反馈；不称商业特效完成。存在图集边缘/脚点/造型一致性与正式动作待修项目。全部具体结果待当前PR CI与独立/用户试玩结论。
