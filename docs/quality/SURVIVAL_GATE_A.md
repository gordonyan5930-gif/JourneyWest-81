## 操作与流程
WASD/方向键移动；鼠标瞄准，按住左键连续轻轻重；Space朝移动方向腾云，停步时朝鼠标。Esc暂停/继续、顶部重试与静音；失焦暂停，恢复后需重新按键。腾云可取消当前挥击（连段清零，已结算接触不重复），不免伤、不穿岩石。

接近桃树：满血仍触发，若受伤限领一次最多30 → 2.8秒方向预警 → 第一阵12名近战分批进入 → 清场和所有箭处理完后喘息3秒 → 第二阵18名（15近战/3弓手）→ 清场结桃，靠近限领一次最多40 → 出口开放 → 悟空实际到达判胜。死亡即失败；终局停止新攻击、刷新与迟到伤害。不是时间播片胜利。

两阵每2.3秒进入一名、四方向轮换；全图同时存活≤18，近战同时开始蓄势≤3。入口靠玩家过近时延后而不贴脸出现，方向提示保留。每名至少进入2.5秒后可开始攻击，另有实际接近距离与可见蓄势；不以出生计时器单独证明反应窗口。
