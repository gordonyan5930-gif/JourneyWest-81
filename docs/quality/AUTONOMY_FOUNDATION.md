# 自主战斗基础 · 单轮范围与实现

基线911e82c8；远端核对后增量开发，不回退。用户已认可移动/攻击和重试，不代表认可本轮自动护卫与整体战斗。

## 复用与适配
- 原SmoothMover/MOVE、sampleMap、gait、美术/PNG母版及两项提示不改；RANGED/ARCHER基础数值不改。
- RangedBattle保留一份资源/蓄势/发射/真实飞行/命中/伤害/打断/击退结算。局部改为敌人实例数组、通用受击对象、cast/shot携带targetId与sourceId。独立技能实验的旧单目标AI作为历史回归保留；主护送通过driver调用新行为，不另起一份破空击引擎。
- EscortRun沿用同一开始/道路/真实到达/失败/重试，增加同一个英雄SmoothMover权威位置、敌人导航/选敌、护卫与避险。画面只读模拟，不在渲染层扣血或判胜负。
- GUARD集中配置；现有World使用旧格子/全队坐标，当前试段复用其CONFIG复活35/3与攻击周期0.8，并对齐悟空180生命/28普攻；只在当前世界坐标中适配复活位置。共享能量继续使用原RANGED恢复3/秒，未改为旧World的5/秒。

## 参数与行为
- 近战：64距离、0.25秒前摇、28真实伤害、0.8秒周期、0.45秒原棒击姿势；命中再查活体/距离/视线。主动破空击清除未命中的近战，姿势目标单独锁定，不能双重结算。
- 警戒270；常规追击目标距唐僧440内。被敌人瞄准时可在原弓射程560内自卫接敌，避免被射却不还击。自动追击与唐僧距离超出440+避险缓冲220时强制进入返回状态，直到100内才再接敌；玩家远处手动命令不受自动拉回。回援明确进入返回状态。手动移动途中不近战截停，到达后可近战身边敌人但不追走。
- 两名弓手入口(1220,380)/(1456,272)，均从开始即在远处可见；速度58，沿原可通行地形寻路，树林/浅滩减速。预警至少3秒、实际先步行60，再满足560射程与视线才能蓄势。蓄势期间停步；射击间隔中必要时继续接近，偏好交战距离290。无突然近身生成、钻地、无限后退或新增近战招式。
- 每敌独立威胁表：近身140压力、近期伤害、距离、当前目标；锁定1.2秒，换目标需超出25分，威胁按4秒衰减，死亡/失去视线/越射程及时重选。近身悟空/受其打击可吸火，未受击的另一名敌人独立决策。旧箭只检查原targetId与原aim，不随转火改向；未实现身体拦箭。
- 避险：受击后2秒、近敌180内或敌人瞄准唐僧形成危险；后方按主要威胁→悟空向量计算，不固定屏幕方向。检查多敌人距离、路径每段沿途风险、可达性和障碍，选后方或局部候选。2秒保留目标，4秒安全再恢复道路；局部避险锚点220、路径长度270，悟空远离/倒地时不能盲追其位置。无自动回血/无敌。
- 求救：生命≤40、持续危险≥2秒、悟空距离≥260或倒地；文字显示3秒、至少间隔8秒；安全4秒后清除。提供相对方向与距离和玩家回援按钮。求救本身不修改手动指令；倒地需先手动耗能复活，不能以回援替代复活。
- 方案B：悟空180生命；倒地不判败，35共享能量、至少3秒后手动复活，复活在唐僧附近重新护卫。能量倒地仍恢复；唐僧不回血。重生位置不是回援传送，两个命令分开。

## 同一操作接口
`EscortRun.command({type:'move',position})` / `{type:'cast',targetId}` / `{type:'rally'}` / `{type:'revive'}`。本轮UI与测试正常操作都走这套命令；将来电脑可复用，不在本轮实现高级托管或导演模式。默认只自动基础近战/护卫/选敌/避险，不自动施放破空击或消耗复活资源。

左键选敌、原有空地点选移动保留；新增仅护送入口的右键强制地面移动并取消瞄准，解决移动敌人覆盖点击位置时“选敌/移动”冲突，不改移动参数。两名敌人有独立选择按钮/金圈/编号及实际瞄准目标显示；开局全景观察远处行进，可切换跟随。

## 验证与边界
无输入观察自主接敌、真实受伤、清敌并抵达；正常指定两个目标与回援，比较实际伤害/打断/近战工作；错误远处驻守可自然失败并触发求救，求救不取消指令；真实倒地/耗能复活；交战、飞行物和倒地后重试。所有正常浏览器流程禁止HP写入、删怪、跳阶段。纯规则单元另覆盖目标锁定/衰减、箭矢原目标、障碍后方/多敌/悟空远或倒地的候选。结果必须标记环境，不把单元或CI软件渲染当Mac验收。

未来团队/一种援军、少女完整片段、托管/导演、完整白骨岭只记路线，未授权实施。无其他主角运行资产、Boss、剧情扩展、账户/商城/credit/收费服务。姿势/受击闪色/倒地角度/复活闪色是复用素材小样，不称正式动画通过。主护送判胜仍要求两敌全处理、无敌箭、唐僧真实存活抵达；不发完整印章。完成本轮并提交独立验收后停止。

- 取证边界：主动技能场景必须正常走位，不能假定悟空固定前出等待两次技能也必胜。站射可能自然倒地；改用实际移动撤回再回援，并记录战况。此为测试操作而非数值/机制修改，不把单次技能的近战次数减少写成所有操作都提高生存率。
