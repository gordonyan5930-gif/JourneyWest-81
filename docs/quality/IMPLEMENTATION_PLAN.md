# P0-Quality Vertical Slice 开发计划

## 固定范围
只验证《梯田少女·少女送饭》一段，不做其余三段，不发放完整白骨岭印章。保留反塔防、自由绕行、自动护卫、悟空可主动离队、唐僧死亡立即失败、其他四角色能量复活、白马死亡下马步行。精美程度、操作与战斗体验须用户人工验收；商业品质是目标，不是本计划的保证。

## 分阶段交付
| 阶段 | 成果 | 测试与证据 | 门槛 |
|---|---|---|---|
| A 美术规范与概念 | 代码审计、风格规范、资产表、单张地图/角色/怪物/HUD原创概念、质量清单 | 静态审计明确事实与假设；概念标记非实机 | 用户审核方向；不默认通过 |
| B 运行场景与动作样片 | 先悟空单角色动作+一屏分层场景；通过后制作其余队伍、可滚动曲折地图、路径反馈、1×2× | 真正运行截图、30—60秒录屏、动作接触帧/无滑步、地图蒙版与相机点击验证 | 用户认可实机画面与动作，才扩展资源 |
| C 密集怪物与危险 | 剧情波次、近战/弓兵/盾兵、拦截职责、攻击时序、低血量预警、普通/困难、开发压力模式 | 自然伤害失败录屏、可赢流程、悟空离队对照、敌人计数和帧时间报告 | 不能靠强制伤害或只靠测试钩子证明难度 |
| D 梯田少女完整片段 | 幻化梯田→提篮送饭→识破→幻身Boss→多向围攻→Boss败退→阶段结算 | 从入口连续玩到结算的无剪辑实机录屏，失败重试、暂停与2×、受保护Preview | 用户与独立验收决定通过；不自动进入其余剧情 |

每阶段在独立提交中提供成果与证据。当前A继续在现有开发分支/PR #1中提交，保持Draft；B/C/D各有明确阶段提交，不合并main。若后续需要单独PR，基于明确阶段边界创建，不能把未验收PR默默合并当作基线。保持当前受保护Vercel Preview，仅游戏项目；不动suibo工业网站，不部署Production。

## 迭代实施顺序
1. 先保留旧技术样例和测试，抽取模拟/渲染边界；地图布局、角色配置、动作事件、遭遇配置各独立。
2. B先实现一个画面和一个完整角色，不先铺满地图或制作所有帧。验证资源可用后扩展至师徒与首段地图。
3. C移除spawnTimer=7的单怪循环，由EncounterDirector根据剧情区域、队伍状态、存活敌数与性能预算排队生成。
4. D复用StoryExtension入口，升级为可保存阶段状态的事件配置；本片段只使用第一段事件，不扩展老妪/老翁/祭坛。

## 波次与难度初案（初始调试值，待试玩调整）
- 小规模3—5，中规模6—12，大规模目标屏内12—25；存活上限/生成速率/远程数量分开配置，达到上限就延迟，不能无限增兵。
- 出生区：前路阻挡、草地侧翼、后方树林；尊重地形、镜头可读性与安全距离，破土至少留可操作的预警窗口；不能在唐僧脚下瞬间完成攻击。
- 普通：较长预警、更少重叠波次、较低远程占比；困难：缩短安全空档、增加多向配合，不给敌人瞬杀唐僧或作弊穿山。
- 密度调整记录：存活人数、唐僧每秒受伤/低血量时长、护卫拦截数、复活消耗、帧时间与胜负。FPS低时先压缩装饰/特效与延缓后续波次，不悄悄取消正在命中的伤害。
- 兵种：近战牵制护卫；弓兵有蓄势弹道和路线绕避机会；盾兵慢速正面阻挡，侧面更脆弱。数值配置独立，不能只有换色。
- 开发压力测试只调用正常波次生成与敌人AI；不直接修改唐僧HP、不自动判败/判胜。正式流程隐藏调试入口，录屏注明是否压力模式。

## 战斗与节奏初案
- 前方八戒拦截，后方沙僧保护，悟空默认守护但主动指令可离队；拦截有数量和距离限制，不能所有攻击永久被单人吸收。
- 远程/迂回敌人可以威胁唐僧，骑乘不等于马替唐僧吸收所有伤害；白马仍有独立HP，死亡后唐僧变慢。
- 悟空基础棒击与短距突进、八戒短冲撞/仇恨反馈、沙僧小范围护盾作为竖切片基础技能候选；明确能量/冷却与结束动作，不提前做完整技能树或毫毛/天兵体系。
- 普通攻击前摇/命中/恢复状态分离；击退、硬直和音效匹配命中帧；2×下模拟结果在相同模拟时间保持一致。
- 行进空档设计为环境变化、远处伏兵/对白或路径选择，不要求无休止战斗；连续无意义空走超过约8秒即进入节奏复核，数值可调。
- 普通难度计划形成“合理干预可赢、完全放任或悟空长期离队可能失败”的可重复示例，不承诺每局或每个随机种子结果相同。

## D片段状态与完成定义
Approach → TerracesMaterialize → GirlOffersFood → WukongSeesIllusion → Reveal → EncounterWaves/BossFight → IllusionDissolves → StageSummary。
所有阶段可通过到达/对话/战斗事件触发，过场允许暂停、提供跳过已看对白但不能跳过必要战斗。Boss击败且唐僧存活、必要波次结束后显示“片段完成”；不表示完整白骨岭通关、不盖章。唐僧死亡随时失败，重试重置剧情与遭遇；复活规则不变。

## 风险和停止条件
A图若不合用户预期，修改风格方案，不用代码特效掩盖风格问题。B资源无法一致导出时停在单角色样片并列出美术依赖，不继续批量生成。性能未测、操作不清晰或正常流程无法输赢，都不能以测试通过结束阶段。没有实际资源与试玩证据，不给商业品质完成百分比或固定交付日期。
