# 原创美术规范 v0.1 · 待用户审核

## 目标与边界
作品定位：精致、灵动、有中国山水意境的2D卡通策略游戏。Kingdom Rush只作为完成度、可读性、动作与反馈的品质参照；不仿制其具体角色、轮廓组合、地图构图、UI、动画、图标、音效或素材。本方案及概念图不是成品美术验收结论。

## 地图设计：白骨岭·梯田入口
建议首片段采用约2.5—3屏宽的连续地图，概念图展示其中一段，不承诺概念图所有细节首版同时完成。曲折山路从近景入口绕过体积岩峰，上行至梯田；草地、疏林、浅溪形成两条可绕行侧路，不能靠绕路跳过少女事件。山体不是重复三角砖，必须有崖壁、坡顶、裂隙、投影与自然过渡。

- 远景：低对比群山和云雾，不可走区域与中景用明确崖线分离。
- 中景：可通行山路、草地、树林、浅水、梯田田埂；岩石、农作物和灌木成组布置，留出行动空间。
- 前景：局部树冠和岩石做框景，遮挡主角时淡出，不把不可见单位藏进装饰。
- 可走的地面与寻路蒙版使用同一布局源；山体边界、溪岸、田埂必须逐段对照。小装饰不暗中挡路，大障碍必须看得见。
- 分层资产：远山/底图、地面材质、障碍、前景遮挡、动态梯田/妖雾、单位、战斗特效、HUD。梯田不能开场全部出现，剧情事件逐步幻化；底图预留空地及遮罩。
- 镜头：队伍推进软跟随、边界限制和手动拖动；主动指挥时保持选中角色可见；重要预警给屏边提示，禁止强制镜头抢走鼠标目标。

## 动画生产标准（不是已完成资源）
先制作悟空单角色动作样片确认画风和动作，再扩展队伍；建议混合精灵图集与可控局部骨骼，最终取决于单角色试制结果。源分层文件、枢轴、脚点、武器挂点与导出配置需交付。方向先试制上下/左右斜向4方向，镜像必须校正持武器手、文字和不对称服饰。

| 状态 | 初始帧/时长建议，可调 | 必要验收点 |
|---|---|---|
| 待机 | 6—8帧 / 0.7—1.2秒 | 呼吸和重心自然、不漂移 |
| 行走/跑步 | 各8—12帧 / 0.5—0.9秒 | 脚步与位移同步；1×/2×不滑步 |
| 普攻 | 8—12帧 / 0.5—0.9秒 | 前摇→接触帧→恢复；命中事件仅一次 |
| 受伤 | 3—5帧 / 0.12—0.25秒 | 清晰短闪/后仰，不能使动作无限锁死 |
| 倒地/死亡 | 6—10帧 | 状态可读、武器不悬空；唐僧死亡立即失败 |
| 复活 | 8—12帧 / 0.6—1秒 | 能量扣除仅一次；恢复可操作时点明确 |
| 基础技能 | 每个选定技能8—16帧试制 | 蓄势、范围、命中/护盾、结束反馈完整 |

悟空/八戒/沙僧需覆盖上述全部战斗状态；唐僧和马按非战斗职责使用对应自保/骑乘状态，不硬加普攻。Boss须有伪装、揭露、待机、移动、攻击、受伤、败退/消散；骷髅须有钻地、行走、攻击、受伤和碎裂。8—12fps仅为动画帧采样建议，渲染目标仍是60fps，不混淆两者。

## 怪物与界面
普通白骨兵使用短刃/骨棒轮廓，弓兵背弓与远距蓄势，盾兵宽盾和慢步；共享骨骼结构和材质，不用同一精灵换色冒充兵种。钻地前有地面破土提示，不可在唐僧脚下瞬间攻击。
HUD采用原创卷轴/青铜/玉质细节，地图占主要画面；顶部阶段、唐僧HP和危机；底部头像/HP/能量/基础技能；1×2×、暂停、归阵、复活均有明确状态。低血量结合头像、条形、声音和不闪烁的边框，不只靠红色。技能冷却/资源不足给原因。

## 音画规范
脚步按地表分组；棒、耙、杖三类打击音色；骷髅破土/碎裂、妖术蓄势和唐僧危险提示各有辨识度。命中音与接触帧同步，技能与普通攻击音量分层，限制并发；提供音乐/音效独立静音。资源须原创或许可明确，不购买付费包。

## 概念图审阅方法
本轮单张场景概念图需同时包含地形、师徒、少女、白骨怪物与界面；它只验证视觉方向。用户优先评价：整体画风、角色造型、场景丰富度、战斗画面可读性。生成图中文字、细节、角色数量与站位仍需人工校对；不能直接切成生产图集或当碰撞地图。
