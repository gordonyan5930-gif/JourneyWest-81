# Quality-B · 最小护送闭环

基线：用户认可cd8be1b4移动/攻击体验。入口：`?sample=quality-b&play=escort`。不是完整白骨岭通关。

## 策划与范围
沿用GAME_DESIGN的自动推进、强敌时暂停、防护唐僧、仅唐僧死亡失败、清敌后仍需抵达出口。骑马/八戒/沙僧/少女Boss/文牒仍按原设计保留，但当前用户禁止扩展其他主角或Boss；本轮只复用唐僧辅助小样步行，不把该表现当作正式骑乘队伍。

## 状态与判定
- ready：点击开始；无敌人攻击、无自动胜负。
- approach：唐僧从(240,720)沿现有ROAD节点前往(750,540)，实际到达才激活弓手(950,525)，不按秒数刷怪。
- encounter：唐僧暂停推进，继续原有35速度/±12范围避险与真实箭矢伤害。玩家选悟空→技能→点击弓手躯干；射程420/冷却3.5/耗能25/伤害55/遮挡/命中/打断原样复用。
- depart：弓手HP=0、唐僧HP>0、所有敌箭已结算，沿既定道路节点前往(1456,272)。击杀弓手不会立即获胜。
- won：唐僧存活、实际距出口≤2、路线走完且威胁解除；只结算护送试段，无印章。
- lost：唐僧HP≤0，冻结本局，允许重试。

唐僧新巡航速度70世界像素/秒（树林×0.8、浅滩×0.65），复用原SmoothMover，只通过该角色导航速度倍率配置；MOVE与悟空操作参数不变。默认悟空前往前方护卫点(850,540)，清敌后自动前往出口；有效手动移动优先，不用自动指令覆盖。普通攻击样片不在此入口伪装成伤害。

## 重试隔离
重新创建RangedBattle和唐僧移动状态；恢复100HP/100能量/0冷却/0命中计数/无cast或shots，敌人初始为未激活。销毁旧飞行物图片，清空双方旧路径、瞄准、受击/倒地显示、检查视角和胜负结果。新局自动路线是新指令，不是上局残留。

## 验证与限制
单元以实际推进/飞行伤害验证遇敌、清敌不提前胜利、真实到达、自然五箭死亡、胜败/施法及敌箭飞行中的重试。浏览器只用按钮和真实指针输入，依次成功→重试后无保护自然失败→重试及冷却中再重试，输出PNG/WebM/JSON；不写HP或跳转阶段。保留所有旧回归。

未新增主角/敌种/Boss/剧情/批量资产，未做正式唐僧步行、骑乘和全队护卫动画。单弓手位置事件只服务本闭环验证，不替代后续多方向波次。Linux Canvas/WebGL短样本不是Mac实机或正式商用品质性能验收。保持Draft、私有仓库、受保护Preview，不合并main/部署Production。
