## 二、游戏定位与核心玩法

### 2.1 反塔防

这款游戏的攻守关系与传统塔防相反。

- 妖怪是防守方，在取经道路上设置防御阵地、埋伏、机关、陷阱和妖术。
- 唐僧师徒是进攻方，必须突破妖怪的防线。
- 师徒默认自动沿取经道路向前行进。
- 玩家通过点击人物、地图以及技能按钮，改变人物路线、攻击目标和战斗策略。
- 玩家可以选择强攻，也可以从草地、树林、小溪等区域绕过部分防线。
- 最终必须满足关卡指定的故事及战斗条件才能通关。

本游戏不是传统塔防，不允许将师徒设计成固定道路上无法控制的小兵。

也不是纯粹手动操作孙悟空的动作游戏。

**游戏核心是自动行进、玩家战术干预、团队协作、妖怪动态布防及剧情闯关。**

### 2.2 参考游戏

重点研究《Kingdom Rush》系列的以下特点：

1. 精致卡通游戏美术。
2. 生动的人物及敌人战斗动画。
3. 英雄主动技能与技能冷却。
4. 召唤援军的操作方式。
5. 角色升级与技能树。
6. 战斗特效、打击反馈、音效。
7. Boss特殊机制。
8. 不同关卡的敌人配置和挑战模式。
9. 关卡奖励、三星评价、敌人图鉴。
10. 易于理解的游戏界面及战斗节奏。

借鉴这些游戏设计原则，但不得复制其美术资源、角色、代码、地图、声音和其他受保护的具体表达。

本项目必须拥有原创中国神话卡通视觉体系。

## 三、画面与技术要求

### 3.1 画面风格

采用2D精致国风卡通画面。

建议：

- 横屏16:9。
- 斜俯视或适合策略游戏的2D视角。
- 色彩丰富，场景具有层次感。
- 人物具有鲜明轮廓和表情。
- 战斗动作流畅。
- 特殊技能具有清晰的视觉反馈。
- 山路、梯田、草地、树林、小溪和山体都应容易识别。

白骨精的妖术表现应带有神秘感，但不应依赖血腥恐怖画面。

第一版允许使用原创简化美术，但不能只用圆圈、方块、Emoji代表最终游戏角色。

至少需要有可辨认的师徒人物、白龙马、骷髅兵、白骨精和场景。

优先保证游戏运行与战斗体验，再完善动画品质。

### 3.2 技术选型

由你根据环境选择合适的网页游戏技术，例如 Phaser、Canvas 或其他成熟2D方案。

要求：

- 在 MacBook 的 Chrome 或 Safari 浏览器中运行。
- 无需付费游戏引擎。
- 完整源码可以交付。
- 游戏数据和逻辑分离。
- 支持本地存档。
- 方便后期添加关卡、技能、角色、怪物和装备。
- 不依赖必须付费的第三方API。
- 优先提供本地可启动的版本。
- 以后能够适配移动端。

不要为了简单而把所有逻辑写成难以维护的单个巨大脚本。如果使用构建工具，请同时提供清楚的一键启动方法。

# 四、白骨岭地图系统

## 4.1 连续地图

白骨岭采用连续的关卡地图。

山路从地图入口逐渐延伸到最终白骨祭坛和出口。

地图必须有可自由移动的区域及自然障碍。

| 地形 | 是否可通行 | 特点 |
|---|---|---|
| 山路 | 是 | 默认行进路线 |
| 草地、草坪 | 是 | 可以绕道 |
| 树林 | 是 | 可以躲避部分攻击，移动稍慢 |
| 浅水小溪 | 是 | 可以通过但可能减速 |
| 山体 | 否 | 作为大的自然路线引导 |
| 悬崖 | 否 | 不能直接穿过 |
| 妖怪机关区域 | 视机关而定 | 可能产生伤害或阻碍 |

山体必须能够真正阻挡寻路，不能只是画在背景上。

玩家点击草地、树林或可通行小溪时，角色应自动寻找合理路径。

如果目标不可到达，应显示提示，不能卡住。

允许绕开部分小妖，但不能跳过必须完成的剧情事件。

## 4.2 动态地图

**这是本游戏最重要的创新之一。**

妖怪的防御环境随着剧情推进不断变化。

例如：

第一阶段，白骨精施法在山路附近幻化出梯田。

第二阶段，在更远处幻化出凉棚。

第三阶段，幻化出茅草屋。

第四阶段，揭露白骨祭坛。

这些场景不能全部在游戏开始时就显露。

必须通过剧情触发，让新的建筑、幻象、埋伏或环境效果逐渐出现。

场景变化应该有动画效果，例如妖雾、粒子、光芒、地面变化等。

幻象被破坏后可以逐渐消散。

地图数据、触发点、建筑物生成和防御阵地配置应独立管理。

# 五、师徒自动行进与玩家操作

## 5.1 默认队形

师徒沿山路自动行进，默认队列为：

**孙悟空 → 猪八戒 → 唐僧骑白龙马 → 沙和尚**

孙悟空在最前方，负责侦察与战斗。

猪八戒在白龙马前，负责前方近战防御。

唐僧骑在白龙马上。

沙和尚在马后，负责防守后方敌人。

无玩家操作时，四名人物按照队形自动向关卡终点前进。

## 5.2 自动战斗AI

- 孙悟空自动攻击靠近队伍的妖怪，并优先保护唐僧。
- 猪八戒自动拦截前方攻击者。
- 沙和尚自动拦截后方及靠近唐僧的敌人。
- 唐僧遇到妖怪时自动尝试躲避，保持在护卫范围附近。
- 白龙马承载唐僧，拥有自己的生命值。
- 队伍遭遇强敌或需要完成剧情战斗时，可以暂停推进或者缓慢推进。

重点避免唐僧在队友战斗时独自冲入敌阵。

## 5.3 玩家操作

参考 Kingdom Rush 的点选交互。

玩家可以：

1. 点击孙悟空、八戒、沙僧或唐僧，查看状态。
2. 点击地图指定位置，命令角色移动。
3. 点击技能图标，然后选择施放位置或目标。
4. 指挥悟空攻击Boss。
5. 指挥八戒回到唐僧身边。
6. 指挥沙僧保护特定位置。
7. 让队伍从树林、草地、小溪绕过妖怪阵地。
8. 暂停游戏，下达战术命令，再恢复战斗。

无操作时，角色返回自动战斗或护送模式。

要清楚显示当前选中角色、移动目标、技能范围、生命值与能量状态。

支持取消指令和恢复默认队形。

# 六、《三打白骨精》完整剧情

白骨岭分为四个连续阶段。

白骨精先后变化成一家三口：**年轻女子、老妇、老翁**。

故事分别为：

1. 少女送饭。
2. 老妇寻女。
3. 老翁寻亲。
4. 白骨祭坛真身决战。

每个阶段都包括环境变化、人物出现、剧情对话、伏兵和Boss战。

## 第一阶段：梯田少女

师徒进入白骨岭，沿山路前进。

白骨精感知到唐僧到来，施展妖术。

山路旁逐渐幻化出一片梯田。

一名年轻女子提着饭篮，从梯田方向走向师徒。

她主动提出赠送食物。

孙悟空察觉妖气，火眼金睛发现少女存在幻术。

剧情触发可以采用角色抵达指定位置的方式。

随着剧情揭露，少女露出妖相，成为小Boss。

白骨精在梯田和附近草地中召唤少量骷髅兵。

骷髅兵从地下爬出，向师徒进攻。

玩家需要击败少女小Boss，并保护唐僧。

这一阶段应相对简单，用于教授基本操作和技能。

小Boss被击败后，少女幻象消失。

梯田可以部分消散，体现妖术被破除。

师徒继续西行。

## 第二阶段：凉棚老妇

师徒向前到达山林区域。

白骨精再次施法，在道路旁幻化出凉棚。

凉棚内出现一名老妇。

老妇声称正在寻找失踪的女儿。

她指责师徒伤害了女儿。

剧情推进后老妇露出妖相，形成第二阶段中Boss。

与第一阶段相比，妖怪的防御强度升级。

战斗包括：

- 凉棚附近埋伏骷髅兵。
- 树林中出现白骨弓箭手。
- 草地上出现白骨陷阱。
- 老妇释放妖雾和控制技能。
- 白骨兵从侧面或后方攻击唐僧。

玩家可以正面强攻，也可以命令部分角色绕过危险位置。

击败老妇中Boss后，幻象消失。

师徒继续前进。

## 第三阶段：茅草屋老翁

师徒进入山岭更深处。

白骨精第三次施法。

道路旁出现茅草屋，代表之前父女三人的家。

一位老翁出现，寻找女儿和妻子。

剧情逐渐揭露后，老翁变化成第三阶段大Boss。

茅草屋成为白骨精的防御阵地。

建议配置：

- 屋顶或高地的骷髅弓箭手。
- 负责阻挡道路的骷髅盾兵。
- 茅草屋附近的召唤法阵。
- 草地与树林中的伏兵。
- 对白龙马的侧面攻击。
- 精英级白骨将军。

这一阶段明显提升难度。

玩家要合理调配孙悟空、八戒和沙僧的技能，不能只依靠悟空单独击杀全部敌人。

击败老翁幻化的大Boss后，白骨精退往山岭深处。

茅草屋幻象逐渐消失。

## 第四阶段：白骨祭坛

进入白骨岭最深处。

白骨精真身出现。

山岭中出现白骨祭坛、妖术符文、召唤阵及大量骸骨。

进入最终Boss战。

### 6.4.1 白骨大军

白骨精召唤山中死去之人的白骨。

骷髅兵从地下不断钻出。

**它们不能只沿固定道路前进。**

必须能够从多个方向出现，并主动围攻师徒。

包括从：

- 道路左右。
- 草地。
- 树林。
- 师徒后方。
- 白骨祭坛周围。

出现位置和数量要合理，给玩家留出反应与绕行机会。

### 6.4.2 白骨爪

白骨精在孙悟空靠近时，突然施放高伤害白骨爪。

应该有明显但较短的前摇动作和特殊音效。

玩家可以让悟空闪避，或使用筋斗云调整位置。

### 6.4.3 筋斗云打断

当白骨精施法召唤骷髅时：

孙悟空可以乘筋斗云飞向Boss，从空中发动金箍棒攻击。

成功命中能够打断召唤。

部分正在生成的骷髅兵会直接碎裂。

必须有清晰的施法进度、打断反馈和骷髅碎裂动画。

### 6.4.4 战术冲突

这是整个关卡最重要的策略场景。

当孙悟空飞去攻击白骨精时，唐僧身边失去了最强战斗力。

白骨精可以趁机召唤白骨兵攻击唐僧。

八戒和沙僧必须自动保护唐僧与白龙马。

玩家可以：

- 继续让悟空攻击Boss。
- 让悟空返回保护唐僧。
- 部署天兵保护唐僧。
- 释放救命毫毛清除白骨大军。
- 让八戒吸引小妖攻击。
- 让沙僧施放护盾。
- 指挥队伍移动到更安全的位置。

### 6.4.5 最终胜利

击败白骨精真身后，不立即结束游戏。

玩家还必须让活着的唐僧抵达白骨岭出口。

**白骨精最终真身被击败＋唐僧安全到达出口，两个条件同时满足才通关。**

之后显示关卡胜利、奖励和通关文牒盖章画面。

# 七、角色技能

技能采用自动普通攻击＋玩家主动技能的系统。

每个角色具有：

- 生命值。
- 攻击力。
- 防御力。
- 移动速度。
- 技能能量槽。
- 技能冷却时间。
- 升级等级。
- 自动战斗行为。

技能能量随时间恢复，最高为100%。

技能消耗、恢复速度和冷却时间可以由游戏配置表调整。

## 7.1 孙悟空

**普通技能：金箍棒**

自动近战攻击，可进行连击。

**主动技能：筋斗云突击**

点击指定目标，悟空乘筋斗云快速飞行，发动空中攻击。

可以打断白骨精召唤技能。

**主动技能：救命毫毛**

能量达到100%时可以释放。

悟空拔下毫毛，变出大量小孙悟空。

建议初始产生12只，升级后可增加到18只或更多。

小孙悟空：

- 自动寻找敌人攻击。
- 拥有独立生命值。
- 有存在时间限制。
- 血量归零或者时间结束后消失。
- 不可以永久存在。
- 优先攻击指定区域内的敌人。

升级后应产生明显视觉变化，包括数量、攻击效果或动作变化。

**主动技能：召唤天兵**

按照冷却时间召唤2—4名天兵。

玩家可以指定地图部署位置。

天兵自动攻击附近的妖怪。

天兵有独立生命值及存在时间。

可以部署在唐僧附近充当临时护卫，也可以部署在Boss附近参与进攻。

**建议后续技能：火眼金睛**

识别妖怪伪装、显示隐藏伏兵或提前发现危险区域。

白骨岭试玩版至少要有可见的剧情识破效果。

## 7.2 猪八戒

普通攻击：九齿钉耙。

主动技能：

1. 野猪冲撞：沿指定方向冲击敌人，造成伤害和击退。
2. 八戒怒吼：吸引附近敌人攻击自己，保护唐僧。
3. 钉耙旋风：旋转武器，对附近敌人造成范围伤害。

主要作用是前方防御、清怪、吸引仇恨和保护白龙马。

## 7.3 沙和尚

普通攻击：降妖宝杖。

主动技能：

1. 护法屏障：给唐僧和白龙马增加临时护盾。
2. 震地击：击退或短暂眩晕附近妖怪。
3. 护送急行：暂时提高队伍移动速度和抗减速能力。

主要负责后方防御、保护及辅助。

## 7.4 唐僧

唐僧原则上不直接攻击敌人。

自动躲避妖怪。

建议主动技能：

1. 佛光护体：短时间提升生存能力。
2. 诵经静心：减轻周围角色受到的控制或妖术影响。

技能强度不能超过悟空、八戒、沙僧。

## 7.5 白龙马

白龙马拥有独立生命值。

死亡后唐僧下马步行，继续由八戒、沙僧保护。

唐僧步行速度降低。

白龙马允许复活。

后期可升级速度、生命值和防御能力。

# 八、死亡与复活机制——最终确认采用方案B

**只有唐僧死亡才立即失败。**

具体规则：

1. 孙悟空死亡，不直接结束游戏。
2. 孙悟空可以消耗技能能量复活。
3. 猪八戒死亡，可以消耗技能能量复活。
4. 沙和尚死亡，可以消耗技能能量复活。
5. 白龙马死亡，可以消耗技能能量复活。
6. 白龙马死亡期间，唐僧下马步行。
7. 唐僧死亡，立即显示失败画面。

技能能量随时间逐渐恢复，最高为100%。

需要设计一个合理、清楚的复活机制。

建议复活采用团队可共享的复活能量，避免角色死亡后自身不能产生能量，造成无法复活的死锁。

复活消耗能量，应有适当冷却或复活延迟。

孙悟空死亡后，唐僧失去最强保护者，复活期间战斗难度会显著增加。

游戏中可以显示角色倒地、复活倒计时、复活按钮和所需能量。

要避免无限低成本复活使游戏失去挑战性。

**不得把孙悟空死亡设计成立即失败。**

# 九、白骨精战术AI——必须实现

不要让白骨精仅仅站在原地按照固定时间释放技能。

应使用可调试的状态机或规则系统，形成对玩家战术的适度反应。

例如：

- 悟空离开唐僧很远，白骨精增加对唐僧的侧面骚扰。
- 悟空接近Boss，白骨精准备白骨爪。
- 八戒和沙僧紧密保护唐僧，白骨精可能派出远程敌人。
- 玩家持续从草地绕路，白骨精可能在前方草地增加埋伏。
- 白骨精正在召唤时，悟空可以通过筋斗云打断。
- Boss生命值降低后，增加白骨兵数量和技能频率。

但必须保证公平：

- AI不能凭空瞬间杀死唐僧。
- 妖怪布防变化应具有提示。
- 敌人出现位置不能无视地形。
- 所有威胁应存在可以采取行动的应对窗口。

白骨精最后阶段可以设置一个名为“万骨狂潮”的特殊技能，短时间提升召唤数量和围攻强度。

# 十一、升级与成长系统

参考 Kingdom Rush 的升级体验，但设计原创技能树。

## 11.1 技能升级

升级分三大类别：

**攻击：**

- 普通攻击伤害。
- 范围伤害。
- 技能伤害。
- 救命毫毛数量。
- 天兵攻击力。
- 筋斗云突击威力。

**防御：**

- 生命值。
- 护甲。
- 护盾。
- 回避能力。
- 唐僧保护效果。

**辅助：**

- 技能能量恢复速度。
- 技能冷却。
- 移动速度。
- 天兵存在时间。
- 小孙悟空存在时间。
- 复活效率。

每种关键技能建议设计3—5级，升级数值由平衡配置表控制。

## 11.2 升级产生视觉变化

这是必须重点实现的体验。

不能只有攻击数值变化。

例如：

- 救命毫毛升级后小孙悟空数量增加。
- 高级毫毛分身拥有不同攻击特效。
- 天兵升级后武器和盔甲变化。
- 沙僧护盾升级后护盾更大或效果更明显。
- 八戒旋风升级后攻击范围扩大。
- 筋斗云升级后飞行轨迹和击中特效更丰富。

试玩版至少实现主要技能的数值和可见效果升级。

## 11.3 关卡奖励与三星评价

战斗可以获得经验、灵力或升级资源。

设计三星评价，例如：

- 一星：完成故事并保护唐僧通关。
- 二星：完成通关并保持较好的护送表现。
- 三星：达到更好的生存、作战和护卫条件。

具体指标由程序配置，不要设计成必须一次全清敌人。

应允许重复挑战关卡。

后续预留英雄挑战、困难模式、敌人图鉴和成就系统。

# 十二、通关文牒系统——核心IP资产

通关文牒是游戏的主要品牌视觉符号之一。

计划共81枚通关印章，对应81关。

每关通关后获得独立的艺术卡片，并在通关文牒中留下对应印章。

## 12.1 美术要求

不能只做普通文字弹窗。

应制作具有独特美术设计的精美卡片。

白骨岭卡片建议：

- 使用中国传统纹样和卷轴元素。
- 融入白骨精、白骨爪、白骨岭及骷髅纹样。
- 具有专属印章图形。
- 有关卡标题、故事信息。
- 显示通关日期和奖励。
- 配有盖章动画和独特音效。

整个通关文牒需要有统一且可辨识的原创视觉语言。

设计时考虑未来可能制作实体收藏卡片、收藏册、徽章和周边产品。

## 12.2 印章和卡片是两个系统

**永久印章：**

记录玩家已经真实完成的关卡。

不可因赠送而丢失，也不能通过收礼直接跳过主线。

**可使用卡片：**

用于恢复生命值、补充技能能量或获得临时奖励。

卡片可以消耗。

应记录卡片数量和使用情况。

## 12.3 玩家赠送卡片

未来允许玩家将通关文牒卡片赠送给其他玩家。

其他玩家接收后，可以凭卡获得：

- 额外生命值。
- 技能能量。
- 一定时间的辅助效果。

但赠送行为不能使接收者自动完成尚未通过的关卡。

卡片使用数量必须有限制，防止破坏游戏平衡。

**本次试玩版：**

必须完成本地卡片获得、收藏、查看和兑换。

多人赠送暂不开发完整服务器。

但是要预留账户ID、卡片ID、所有权、转赠、领取和兑换状态等数据结构，便于后续开发联网功能。

不要在试玩版里假装已经完成真实多人赠送。

# 十四、战斗平衡

第一版建议一局约8—15分钟，具体以实际试玩调整为准。

四个剧情阶段应逐渐增加压力。

少女阶段主要用于教学。

老妇阶段开始引导路线绕行和技能使用。

老翁阶段要求团队协作与护卫。

最终阶段重点考验悟空进攻Boss和八戒、沙僧保护唐僧的策略选择。

必须确保：

- 玩家不主动操作时，队伍也能做基本的自动攻击和保护。
- 但合理使用技能和改变路线应明显提高胜率。
- 孙悟空不能单独无风险解决所有敌人。
- 白骨大军数量多，但不能造成明显卡顿。
- 玩家可以选择绕过一些怪物，而不是必须全部清除。
- 卡片、复活、召唤技能不能无限叠加而破坏难度。

所有关键数值放入独立配置中，方便后续调试。
