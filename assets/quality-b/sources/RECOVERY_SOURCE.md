# 悟空最小倒地/起身姿势来源

现有运行图集缺倒地/起身，用户本轮允许最少必要素材。本轮用image_gen参照现有悟空运行图集制作一条4姿势透明底原画：降低重心、跪地待复活、撑棍起身、站立护卫。要求保持成年史诗神话孙悟空、金毛、铜金甲、红披风、虎皮裙/金箍棒，同视角等比例、脚线对齐，不含其他角色/场景/文字。不是新的正式人物母版，也不替代assets/references的两张原始PNG。

原生成PNG：2172×724、1262226字节、SHA-256 `06cd15d3e6d9521439c580950241621968312630e4064b37b5585516687652a8`。大blob连接未完成，改为4个原字节分片上传；不是重新生成或有损压缩。`recovery-source-archive.json`记录顺序、字节数和各片校验；`npm run restore:recovery-source`验证后还原同名PNG。原始生成文件同时保留在执行工作区，恢复脚本不依赖该工作区。

`scripts/pack-recovery.py`只做工程裁格、统一缩放和透明填充，原图不重绘；输出2560×640/4×640方格WebP+JSON，脚线592，见recovery-audit。源PNG不在普通构建中解码，运行仅载280516字节图集。

4关键姿势是小样，不是已验收连续动画。缺更细倒地/受击/起身过渡、独立受击姿势；起身与奔跑混接仍待实机/人工修订。版本0.1，未经用户认定为正式生产资源。图像额度/金额无接口，需人工核对。
