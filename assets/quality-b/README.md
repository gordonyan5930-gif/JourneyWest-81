# Quality B · 首次可运行资产试制 v0.1（待审核）

依据本轮可见的用户批准母版，重新生成独立地图底图与透明悟空动作图集；不是把概念板裁入游戏。原始生成PNG保留在执行工作区generated_images；运行资源转为WebP，sprite使用无损编码，地图使用quality95编码。manifest.json保存实际运行文件SHA-256及生成源PNG校验值；atlas.json仅描述原图均匀4×2帧区域，不重绘/伪造原件。

- 地图：1672×941，无角色、UI或图板文字。人工配置与路面一致的山路/草地肩部/过石浅滩通行走廊；可在样片显示蒙版，边缘一致性仍待人工审查。
- 悟空：1774×887 RGBA，4跑步帧、2待机帧、2攻击姿势。统一右向3/4视角，左行镜像；不是完整方向/表情/受伤/倒地/复活/技能体系。
- 已知美术限制：生成帧的武器/披风可能有边界裁切、身份细节和脚点轻微抖动，攻击仍是关键姿势不是成套精修动作；后续需人工清线与逐帧审核。不宣称生产级动画合格。
- 入口：`?sample=quality-b`，Canvas对照加`&renderer=canvas`。原技术版保留，玩法/生命/复活规则未被本单角色样片替换。
- 本入口只试制地图行走、镜头、脚点和棒击展示；不含少女剧情、敌人战斗、其余角色或印章。
- 本机采样按钮导出当前浏览器真实UA、渲染类型、平均FPS/p95、可获取的heap；只有用户真实设备导出的JSON才可作为该设备证据。CI数据不冒充Mac/Safari。
