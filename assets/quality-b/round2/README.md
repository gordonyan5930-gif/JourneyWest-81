# Round2 current-cast motion study

Only current Wukong, Tang and skeletal archer assets.24 Wukong strike frames (8/8/8),8 Tang gait,8 archer gait,12 archer reaction/fall/rise frames. Runtime frame/texture/pivot/facing/scale in index.json; no anatomy is generated by code or interpolated from old four poses. Registration and source boundaries are engineering crops/padding, not animation quality approval.

Seven image-generation calls; three earlier candidates rejected for gait or gutters and retained in source manifest. Four selected sheets still require hand cleanup of source-border touches, cape/hand continuity and proportions. Archer second half of gait is natively left-facing; runtime normalizes its facing per frame. Do not count mirrored orientation as a newly drawn pose.

Sources are byte-exact numbered chunks in sources/manifest.json, each with dimensions/bytes/SHA-256. Restore PNGs to /tmp with npm run restore:round2-sources. Approved references and original map are unchanged. These are unapproved animation studies, not formal production resources. Built-in image generation used no purchased asset/service; actual account costs unavailable.

To reproduce engineering packing after restoring originals: `ROUND2_SOURCE_DIR=/tmp/journeywest-round2-originals python3 scripts/pack-round2-art.py` (Pillow needed; not required at runtime/build). Generated originals are never redrawn by this script.
